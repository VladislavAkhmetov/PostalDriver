# «Рейс в Заречье» — Симулятор УАЗ «Буханка»

> **Жанр:** Медитативный симулятор вождения / Road-trip с элементами atmospheric narrative  
> **Стек:** Three.js, Vite, WebGL, TypeScript, Web Audio API  
> **Вид:** От первого лица (из кабины УАЗ-452 «Буханка»)  
> **Визуальный стиль:** 3D-окружение с PS2-ретро эстетикой (низкополигональные болванки + Nearest Neighbor пиксельные текстуры + билборд-деревья)

---

## 🎯 Цель рейса

Короткая игра на 10–12 минут: две доставки, Сосновка и Заречье. Рейс оценивают по двум вещам, и они тянут в разные стороны.

- **График.** Сельпо в Заречье закрывается на обед через **12 минут** (время с работающим мотором). Отсчёт и опоздание показаны в маршрутной полосе.
- **Посылки.** В кузове банки и стекло. Сильные удары подвески на ямах и столкновения бьют груз: процент целости виден в полосе, в кузове звенит, Валентина при вручении ворчит.
- **Переезд — гонка с поездом.** Лампы загораются тогда, когда к переезду подъехал бы водитель на 65 км/ч. Кто едет живее, проскакивает; кто медленнее, ждёт состав около 40 секунд. А рядом пост ГАИ с радаром.
- **ГАИ.** Штраф, погоня, задержание (−2,5 минуты графика) или уход в лес.

В конце начальник отделения ставит оценку от «2» до «5». «Пятёрка» — только без замечаний: вовремя, посылки целы на 90 % и больше, ГАИ ни при чём. Лучший результат сохраняется в браузере и показывается на титуле.

Ориентиры (замерены автопилотом на настоящей физике): по асфальту около 85 км/ч, по грунтовке около 30 км/ч — успеваешь с запасом около минуты, посылки целы примерно на 90 %. Если гнать под 50 по ямам, приедешь на 9 минут, но с 70 % груза.

## 🚙 Физика поведения УАЗ-452 «Буханка»

Физическая модель вождения создана с особым вниманием к деталям поведения культового советского вездехода:

1. **Бескапотная компоновка (Cab-Over Seating):**
   - Водитель сидит строго над левым передним колесом и двигателем (`x: -0.48, y: 1.25, z: 0.90`).
   - Наезд на кочку или провал в колею передним колесом мгновенно подбрасывает водителя вверх и наклоняет голову с резким ускорением еще до того, как препятствия коснутся задние колеса.
   - При резком торможении («носом в землю») водитель кивает вперед, а при ускорении откидывается назад.

2. **Зависимая рессорная подвеска (Solid Axles on Leaf Springs):**
   - Высокий центр тяжести автомобиля (~0.85 м) в сочетании с отсутствием жестких стабилизаторов создает аутентичный крен кузова на дуге поворота.
   - Нелинейная жесткость рессор: мягкая работа на средних амплитудах и жесткий упор при глубоких ударах.
   - Дрожь и микросотрясения от мелкой гребенки («стиральной доски») гравийного грейдера.

3. **Трансмиссия и Раздаточная коробка:**
   - 4-ступенчатая механическая коробка передач + задний ход.
   - Раздатка с двумя рычагами:
     - **Рычаг 4WD:** подключение жесткого привода переднего моста (50/50).
     - **Рычаг пониженной передачи (4L):** передаточное число **1.94:1** (демультипликатор) удваивает тягу на колесах, позволяя медленно, но верно ползти на 3–8 км/ч через топкую болотную колею, где обычный 2WD сразу буксует и глохнет.
   - Механический ручник, блокирующий заднюю ось (необходим для ритуала сдачи почты и стоянки на уклонах).

4. **Физика дорожных покрытий и колейность:**
   - **Асфальт:** твердый зацеп ($\mu = 0.95$), легкий накат, ровный гул шин.
   - **Сухая грунтовка:** мелкая вибрация, среднее сцепление ($\mu = 0.72$), клубы пыли.
   - **Глинистые колеи (Урочище Глухово):** колеса проваливаются на глубину до 18 см, резко возрастает сопротивление качению. Действует боковая затягивающая сила колейности — при попытке вывернуть руль из колеи шины упираются в глиняный бруствер. Без 4WD и понижайки машина вязнет.
   - **Лужи:** брызги на стекло, динамическое сопротивление воды.

## 🎮 Управление

| Клавиша / Действие | Функция |
|---|---|
| **W** / **Стрелка вверх** | Педаль газа (Акселератор) |
| **S** / **Стрелка вниз** | Педаль тормоза / Задний ход |
| **A / D** / **Стрелки влево/вправо** | Поворот руля (червячный редуктор с инерцией и возвратом) |
| **ПРОБЕЛ** (или клик по ручнику) | Стояночный тормоз (Ручник) |
| **4** (или клик по левому рычагу) | Включение/выключение полного привода (4х4) |
| **L** (или клик по правому рычагу) | Включение/выключение понижающей передачи (4L) |
| **1, 2, 3, 4** | Переключение передач МКПП |
| **H** (или клик по кнопке на руле) | Клаксон («Би-бип!») |
| **P** (или клик по тумблеру) | Включение/выключение дворников |
| **M** (или клик по планшету) | Открыть/закрыть бумажную карту маршрута |
| **C** (или клик по магнитофону) | Радио: включить / выключить; **N** — следующая FM-станция |
| **F2** | Смена погоды (Золотая осень / Хтонь / Ливень / Туман) |
| **F3** | Переключение режима PS2 ретро-пикселей / Native |
| **Мышь (ЛКМ)** | Интерактивный клик по приборам и рычагам в кабине |

## 📬 Ритуал доставки в деревнях

Навигация ведется **без мини-карты и GPS** — исключительно по синим дорожным знакам ГОСТ, километражу и приметам (вышка, мост, водокачка).

Чтобы выполнить доставку:
1. Въехать в деревню к опознавательному объекту (магазин Сельпо, автобусная остановка, медпункт).
2. Полностью остановиться.
3. **Затянуть ручной тормоз** (`ПРОБЕЛ` или клик по рычагу).
4. **Дважды посигналить в клаксон** (`H` или клик по рулю — «Би-бип!»).
5. Почтальонка Валя передаст почту, на экране появится атмосферная диалоговая зарисовка, а на бумажной карте пункт автоматически **вычеркнется красным карандашом**.

## 🚨 Пост ГАИ, погоня и задержание

За городом, на 60-й зоне, стоит пост ГАИ: радар «Барьер-2», инспектор с жезлом и патрульная машина — от рейса к рейсу то легковая, то внедорожник (CC0-модели в ливрее ГАИ, с сине-красной «люстрой» и экипажем из двух человек за тонированным стеклом). Те же машины ГАИ встречаются и в потоке; внедорожник ездит и по грунтовке.

- **Остановился по жезлу** — инспектор подходит к окну: предупреждение, штраф 50 ₽ или проверка документов.
- **Не остановился** — погоня: мигалка, сирена, голос через мегафон. На асфальте патруль быстрее буханки: догонит, пойдёт на обгон, подрежет и затормозит перед носом.
- **Остановился во время погони или протаранил патруль** — задержание: оба милиционера выходят, сержант у водительского окна, напарник прикрывает пассажирскую сторону. Протокол, наручники, затемнение — «Отделение ГАИ, Ключевск», два часа на скамейке и штраф 200 ₽ (за таран — 500 ₽).
- **Уйти можно в лес.** На развилке сверни на грунтовку и включи передний мост: легковая ГАИ на бездорожье не полезет и отстанет у развилки. Внедорожник поедет следом, медленнее по ямам, пока не сядет в самом глубоком болоте, — а УАЗ с 4×4 его проходит.

Итог рейса пишется в путевой лист: штрафы, задержания, «ушёл от погони».

## 📻 Аудиосистема и Звуки (Web Audio API)

- Процедурный синтез тактов 4-цилиндрового карбюраторного мотора ЗМЗ/УМЗ (холостые 750 об/мин, надрывный рев под нагрузкой).
- Фирменный вой прямозубых шестерен раздатки при наборе скорости.
- Скрип рессор и глухие металлические удары подвески на ухабах.
- Работающие стеклоочистители со смахиванием капель дождя.
- Магнитофон «Былина» / «Весна» с 4 ностальгическими мелодиями, шипением магнитной пленки и щелчками механизма.

## 🚀 Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-билда
npm run build
```
Сервер запустится по адресу: `http://localhost:3000`

## 🙏 Модели (CC0)

- **УАЗ-452 «буханка»** — «UAZ-452 Utility Van Lowpoly», автор **Mehozavr**, [OpenGameArt](https://opengameart.org/content/uaz-452-utility-van-lowpoly), CC0. Текстура перекрашена в почтовую ливрею 1990-х: светлый верх, почтовый синий низ, надпись «ПОЧТА», «Ключевский районный узел почтовой связи», эмблема с почтовым рожком, номер М 417 ВН 62. Во встречном потоке та же модель ездит в оранжевой ливрее аварийной газовой службы (авторская текстура) и в сером. Подробности — `src/assets/uaz/CREDITS.md`.
- Люди и легковые машины — паки Quaternius (CC0), см. `src/assets/people/CREDITS.md` и `src/assets/cars/CREDITS.md`.
