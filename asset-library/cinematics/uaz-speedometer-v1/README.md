# Спидометр — сохранённый оригинал для роликов

Сохранён 2026-11-09 по прямому указанию пользователя. Не удалять и не упрощать.
Для игрового варианта создавать отдельную производную модель.

- `model/uaz-speedometer.glb` — исходный GLB с встроенной текстурой, 3864 треугольника.
- `model/speedometer-dial.png` — оригинальная текстура шкалы 512 × 512.
- `source/speedometer.blend` — редактируемая сцена с упакованной текстурой.
- `source/build-speedometer.py`, `source/speedometer-texture.py` — снимки генераторов.
- `source/prototype-notes.md` — технические заметки первоначального прототипа.
- `preview/` — проверенные кадры из Three.js.
- `manifest.json` — контрольные суммы сохранённых файлов.

GLB и текстура скопированы побайтно. В Blender-файле изменено только хранение
текстуры: она упакована внутрь, чтобы сцена не зависела от рабочих папок.
Снимки генераторов сохраняют прежние пути относительно корня проекта;
для повторного запуска использовать рабочие скрипты в `scripts/models/`
или перенести снимки в аналогичную структуру отдельного проекта.

Это интерпретация фотографий пользователя, а не точный заводской обмер.
Принятый диаметр — 112 мм. Показание одометра декоративное.

Папка не входит в игровые загрузки. Она предназначена для хранения оригинала,
крупных планов, катсцен и рекламных роликов.
