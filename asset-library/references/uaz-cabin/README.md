# Референсы кабины, предоставленные пользователем

Сохранены все семь вложений из обсуждения кабины. Файлы скопированы без
изменений, контрольные суммы проверены. Пользователь прямо попросил не терять
референсы. Не удалять при чистке проекта. Хранить вне игровых загрузок.

## Фотографии

- `photos/03-cabin-wide-metal.png` — основа общей компоновки: торпеда по ширине,
  отдельный спидометр справа от руля, малые приборы слева, бардачок справа,
  рулевая колонка, педали, рычаги, кожух двигателя, двери. Тонкий трёхспицевый руль.
- `photos/04-dashboard-oblique.png` — основа профиля торпеды, загиба кромки,
  посадки круглого прибора и размещения переключателей. Дополнительные предметы
  не следует принимать за обязательную заводскую комплектацию.
- `photos/02-cabin-wide-padded.png` — дополнительный общий вид объёма кабины,
  верхней полки и ветрового окна. Отличающиеся руль, обивка дверей и стёганый
  чехол не должны автоматически переноситься в основной вариант.
- `photos/01-dashboard-oblique-initial.png` — первоначальный референс из
  первого сообщения, сохранён отдельно от повторного вложения похожего вида.

Фотографии показывают разные исполнения и доработки. Не смешивать все детали
в одну произвольную комплектацию. Основой принять общий вид металлической
кабины и косой вид торпеды; остальные изображения помогают понять объём.
Год выпуска и точные размеры по этим фото не установлены.

## Игра до переделки

`game-before/01-driver-forward.png`, `02-side-window.png`,
`03-dashboard-and-wheel.png` — исходные скриншоты проблемной кабины.
Это материал для сравнения, а не образец геометрии новой модели.

## Последовательность следующей работы

1. Цельная оболочка торпеды: верхняя полка, передняя стенка, загибы кромок,
   правая крышка бардачка. Согласовать с основанием ветрового окна и дверями.
2. Компоновка основных приборов и органов управления на этой оболочке.
   Использовать одобренный игровой спидометр; малые приборы решать экономно.
3. Проверка из водительского положения и при взгляде в стороны; затем
   подключение стрелок, кнопок и рычагов к состоянию игры.
4. Замер всей сцены с кабиной, окружением и зеркалами. Декор добавлять после
   проверки архитектуры, силуэта и стоимости кадра.

Приоритеты пользователя: аутентичность, расположение приборов, общий вайб,
архитектурная целостность и быстродействие. Читаемость шкал вторична.
