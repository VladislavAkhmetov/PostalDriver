# Кабина: пробный спидометр

Отдельный образец по трём фотографиям пользователя: круглый прибор справа от
рулевой колонки. В рабочую кабину не установлен. Это визуальная интерпретация,
а не обмер конкретной заводской модификации. Диаметр ободка 112 мм принят
для прототипа; его следует уточнить при компоновке торпеды. Шкала 0–120 км/ч,
декоративный одометр 047218 и надписи нарисованы заново; одометр не связан
с пробегом игры.

## Просмотр

Запустить `npm run dev` и открыть `/speedometer-preview.html` на адресе Vite.
Страница также включена в производственную сборку. Мышь вращает модель,
колесо приближает, ползунок управляет скоростью, кнопка проверки запускает
проход стрелки по шкале. «Ретро» уменьшает разрешение только этого просмотра;
это не полный постпроцессор игры.

Модель: `public/models/cabin-prototype/uaz-speedometer.glb`.
Текстура шкалы: 512 × 512, встроена в GLB и отдельно сохранена рядом.
3864 треугольника, восемь отдельных мешей. Статическую часть можно объединить
после окончательного выбора материалов; стрелку нужно оставить отдельной.

## Изготовление

Геометрия создана Sand3D 1.6.3: профили вращения для корпуса, прокладки,
завальцованного ободка и внутренней кромки; выдавливание профиля стрелки.
Blender добавляет UV-развёртку шкалы, экспортирует GLB и делает студийные рендеры.
В этом окружении выполнено через установленный Blender 5.0.1; это проверка
данного скрипта, а не заявление о поддержке всех функций Sand3D в Blender 5.0.

Генератор текстуры требует Python с Pillow. Sand3D установлен локально,
без замены установленного Blender и без добавления зависимости игре:

```powershell
& 'C:\Users\amazi\AppData\Local\Programs\Python\Python311\python.exe' -m pip install sand3d==1.6.3 --no-deps --target node_modules/.sand3d-tools
& 'C:\Users\amazi\AppData\Local\Programs\Python\Python311\python.exe' scripts/models/speedometer-texture.py
& 'D:\Program files\Blender\blender.exe' --background --factory-startup --python scripts/models/build-speedometer.py
```

## Подключение к игре

Имя узла стрелки — `speed_needle`. После загрузки GLB его ось вращения +Y;
угол в градусах `135 - 270 * speedKmh / 120`, скорость ограничивается 0–120.
В просмотре внешний контейнер повёрнут на +90° вокруг X, чтобы лицевая
сторона смотрела вдоль +Z и вертикаль шкалы совпадала с +Y в Three.js.
Скорость сглаживается независимо от частоты кадров; текущий вариант —
демонстрация отклика, без шума и механических колебаний.

Рендеры Blender служат проверкой формы. Для оценки игровых материалов
использовать `reports/cabin-prototype/threejs-preview.png` и живой просмотр.
Там же сохранены кадры 0, 60 и 120 км/ч, статистика модели и отчёт браузера.

## Проверка

`npm run build` проверяет TypeScript и сборку игры с просмотром детали.
`scripts/playtest/speedometer.mjs` открывает отдельный фоновый Chrome с временным
профилем, проверяет загрузку модели, ползунок, автоматический ход и ретрорежим,
сохраняет скриншоты и ошибки. Для этого теста Vite должен работать на
`http://127.0.0.1:4317`.

Библиотека: https://github.com/Sandflow-ai/sand3d (Apache-2.0).
Модели из датасетов Sand3D не использованы.
