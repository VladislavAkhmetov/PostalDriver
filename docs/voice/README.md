# Озвучка «Сельской почты»

Игра — текстовая: каждая реплика стоит на экране субтитром. Озвучка ложится поверх, по строке: есть файл — строка звучит, нет файла — всё как было. Можно озвучивать постепенно — одного персонажа, одну сюжетку, одну реплику.

## Как это устроено

- У каждой строки — **id**, хеш её текста: `v0abc123`. Файл записи называется так же: `src/assets/voice/v0abc123.mp3` (подходят `.mp3`, `.ogg`, `.wav`). Положил файл — после пересборки строка звучит. Код трогать не нужно.
- **Сценарий** — `docs/voice/script.csv` (таблица: id, роль, подпись в игре, где звучит, текст, место в коде, записано ли) и `docs/voice/by-speaker.md` (то же, по ролям). Собирается командой `npm run voice:script` прямо из исходников — после правки текста его надо пересобрать: **изменился текст — изменился id**, старая запись перестанет звучать (так и задумано: голос не будет говорить устаревшее).
- **Шаблоны** («{…}» в сценарии) — строки, куда игра подставляет место, сумму или имя: «Подвези {…}, а?» звучит как «Подвези до Сосновки, а?», «…до Заречья…». Каждый вариант — своя запись со своим id. Варианты собирает прохождение (`docs/voice/heard.json`, см. ниже) — `npm run voice:script` добавит их в сценарий.
- **Что звучит:** реплики под картинкой (`реплика`, `у адресата`), вопросы на карточках (`вопрос`), страницы альбома и затемнения (`страница`, `затемнение` — читает рассказчик), ведущая радио (`радио` — звучит через тот же «старый приёмник», что и песни, вместо её «бормотания»). Ответы игрока (`ответ игрока`) — по желанию: обычно их не озвучивают, Тимур молчит.
- **Что не звучит:** подсказки управления, всплывающие сообщения, записки под дворником, путевой лист, журнал.
- Пока голос говорит, радио в кабине приглушается до трети и потом возвращается; субтитр держится, пока не кончится запись. Новая реплика обрывает предыдущую.

## Запись

- Моно, 44,1 или 48 кГц, без музыки и эффектов; паузы в начале и в конце — не больше 0,15 с. Громкость ровная, около −16 LUFS (речь), пики не выше −1 dBFS.
- Формат файла для игры: mp3 96–128 кбит/с или ogg q4. Имя — строго id из сценария.
- **Без «радийности»**: голоса в кабине и у окна — чистые, обработку для ведущей радио игра делает сама (полоса старого приёмника, шипение, провалы плёнки). Ведущую записывать так же чисто.
- Акцент — мягкий, живой, без пародии. Башкирские и татарские слова (улым, рәхмәт, әйдә, картатай, өләсәй, әсәй, апа, агай) — с родным произношением.

## Черновая озвучка (синтез)

**Сейчас озвучки в игре нет:** черновики синтеза из `src/assets/voice/` убраны — синтетические голоса портили атмосферу. Игра текстовая: реплики идут субтитрами, радио звучит без ведущей. Код (`src/audio/Voice.ts`), сценарий (`script.csv`) и генератор черновиков остались — файлы `v…mp3` сюда кладутся снова, когда будут настоящие записи. Ниже — как черновики делались (`docs/voice/drafts.json` — их прежний список).

- **Чем:** Silero TTS v5 (русский), пять голосов — `aidar`, `eugene` (мужские), `baya`, `kseniya`, `xenia` (женские); каждая роль — свой голос, высота и темп (таблица `CAST` в `scripts/voice-draft.py`). Ударения и «ё» модель ставит сама; клавиши («M», «Esc») и башкирские/татарские слова читаются по словарю `SAY` там же («өләсәй» → «олэсэ+й», «улым» → «улы+м», «рәхмәт» → «рахмэ+т»).
- **Проверено распознаванием:** каждый файл прогнан через Whisper (small) и сравнен с текстом — средняя ошибка по символам около 3 %, то есть голос говорит то, что написано.
- **Не для релиза.** Модели Silero — CC BY-NC-SA (некоммерческая лицензия). Перед Steam черновики заменяются: актёрами (лучше всего) или коммерческим синтезом — Google Cloud Text-to-Speech (голоса ru-RU WaveNet / Neural2, первые ~1 млн символов в месяц бесплатно, весь сценарий — около 60 тыс.), Yandex SpeechKit, Azure Speech, ElevenLabs. Голоса Piper `ru_RU-denis` и `ru_RU-dmitri` — CC0, их можно и в релиз, но звучат проще.
- **Пересобрать** (после правки текста — у новой строки новый id):
  ```sh
  python3 -m venv /tmp/tts && /tmp/tts/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu && /tmp/tts/bin/pip install soundfile numpy scipy
  curl -L -o /tmp/v5_ru.pt https://models.silero.ai/models/tts/ru/v5_ru.pt
  /tmp/tts/bin/python3 scripts/voice-draft.py --model /tmp/v5_ru.pt          # только недостающие
  /tmp/tts/bin/python3 scripts/voice-draft.py --model /tmp/v5_ru.pt --only kartatay --force   # переозвучить роль
  npm run voice:script                                                       # отметки «черновик» в сценарии
  ```
- **Настоящая запись поверх черновика:** положить файл с тем же id (`v…mp3`) и убрать этот id из `docs/voice/drafts.json` — тогда генератор его больше не тронет, а сценарий отметит «да».
- Черновики — mp3 32 кбит/с, моно, 24 кГц, около −18 LUFS, паузы по краям обрезаны.

## Проверка

- В dev-сборке (`npm run dev`) в консоли: `__uaz.voice.heard` — всё, что прозвучало за сессию (id, подпись, текст, есть ли запись). `copy(JSON.stringify([...__uaz.voice.heard.values()]))` — и вставить в `docs/voice/heard.json`, чтобы добавить в сценарий варианты шаблонов.
- `npm run voice:script` в конце пишет, сколько строк уже записано.
