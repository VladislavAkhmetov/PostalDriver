# Картинки пролога

Сюда кладутся иллюстрации к страницам пролога (`src/game/Prologue.ts`). Имя файла — id страницы, расширение `.webp`, `.jpg` или `.png`. Пока файла нет, на странице стоит рамка-заглушка с описанием кадра.

Стиль — как отпечатки из семейного альбома 1998 года: «мыльница», плёнка «Кодак»/«Свема», тёплый пересвет, зерно, местами смаз. Время — **май и июнь 1998-го**, дождливые: молодая зелень, черёмуха и сирень в цвету, мокрый асфальт, лужи, грозовое небо. Без логотипов и надписей (рыжую дату в углу игра печатает сама).
