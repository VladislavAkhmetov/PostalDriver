# Кассеты для магнитолы

Положи сюда свои аудиофайлы (`.mp3`, `.ogg`, `.m4a`, `.aac`, `.wav`, `.flac`, `.opus`) —
они появятся в магнитоле УАЗа как кассеты, в алфавитном порядке, перед FM-станциями.
Имя файла показывается как название трека (`Кино - Группа крови.mp3`, `ДДТ - Осень.mp3`).

Песни Цоя, ДДТ и других защищены авторским правом, поэтому в игру они не вшиты —
положи сюда свои купленные или оцифрованные записи. Без файлов русский рок играет
в эфире: станции «Наше Классика» и «Наше Радио» в магнитоле (`N`).

Управление: `C` — включить/выключить, `N` — следующая кассета / станция.
Файлы можно также вставить прямо в игре: «Пауза → Вставить свою кассету…»
или перетащить их в окно.
